IMEN BIJOUX — VERSION 3

PUBLIER LA MISE À JOUR
1. Dans l'application ACTUELLE : Sauvegarde > Télécharger la sauvegarde. Garde ce fichier en lieu privé (il n'est pas chiffré).
2. Extrais le ZIP. Dans le dépôt GitHub imen-bijoux-app : Add file > Upload files > ajoute les fichiers extraits (à la racine) > Commit changes.
   Tu peux supprimer l'ancien fichier inutile manifest.webmanifest.
3. Attends quelques minutes, ferme l'application, rouvre-la dans Chrome (recharge une 2e fois si l'ancienne s'affiche).
   Utilise la même adresse et le même navigateur qu'avant. N'efface pas les données du site.
4. Crée ton mot de passe (8 caractères minimum). Les anciennes données sont reprises puis chiffrées.
5. Vérifie les données, puis fais une sauvegarde chiffrée. Quand tout est confirmé, supprime l'ancienne sauvegarde non chiffrée.

MOT DE PASSE
- Oublié = données et sauvegardes chiffrées perdues. Aucune récupération possible.
- Une sauvegarde garde le mot de passe qu'elle avait le jour de sa création.
- Verrouillage après 10 minutes sans activité (une saisie non enregistrée est perdue).

SAUVEGARDE SUR ANDROID OU ONEDRIVE
- Le fichier arrive dans « Téléchargements » du téléphone.
- OneDrive : ouvre l'application OneDrive > + > Importer > choisis le fichier.
- La sauvegarde n'est pas automatique. Restaurer remplace les données : ce n'est pas une synchronisation.

RÈGLES DE CALCUL
- Chiffre d'affaires = ventes livrées ou payées au comptoir, moins les colis non livrés.
- Aucun remboursement : après livraison, échange uniquement (même article ou un autre).
- Colis non livré : 3 TND par dossier (pas par pièce). Échange : 9 TND si ton erreur, 0 sinon (modifiable).
- Pièce retournée non revendable : son coût est compté en perte.
- Échange avec un article d'un autre prix : la différence de prix n'est pas calculée.
- Solde Novax : à comparer avec les bordereaux.
- Une vente ou un achat faux s'annule puis se ressaisit.
- Les anciens retours en double ou colis « retournés » sans dossier ne sont pas corrigés automatiquement : vérifie-les.

LIMITES
- Pas de synchronisation en ligne entre appareils, pas de comptes séparés.
- Le mot de passe protège les données de l'appareil. La page et le code restent publics, sans tes données.
- Photos : limitées par l'espace libre de l'appareil. Une très grosse sauvegarde peut échouer sur un petit téléphone.
- Le navigateur ou un effacement des données du site peut tout supprimer : sauvegarde chaque semaine.
- Prototype, non audité en sécurité, pas un logiciel comptable certifié.
